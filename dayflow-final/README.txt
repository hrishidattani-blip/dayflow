DAYFLOW — FUNCTIONAL PROTOTYPE

Open index.html in a modern browser. No install or server is required.

Verified interactions:
- Today / Routine / Insights navigation
- Add, edit, delete and complete activities
- Completion percentage and next-up card
- Woke-up-late, low-energy, and schedule-shift adjustments
- Reset today's changes
- Routine editing and saving
- Dark/light theme
- Local browser persistence
- Clear local data
- Responsive mobile layout

This is a local-first MVP. It does not yet include accounts, cloud sync, payments, notifications, calendar integrations, or AI.
